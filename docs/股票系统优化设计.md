> 状态：已落地实现，与代码一致
> 代码基线：`server/src/modules/stock/engine.ts`（核心纯函数）、`server/src/modules/stock/stock.service.ts`（推进轮次与做市商）、`server/src/modules/stock/dto/stock.dto.ts`（配置 DTO）

## 1. 实现总览

优化后股票系统的核心是**供需驱动 + 成交价锚定**的定价模型，不再出现「一直涨停或一直跌停」的锯齿封板：

| 模块 | 实现位置 | 核心改进 |
|------|---------|---------|
| 撮合 | `computeMatch()` | 最高买/最低卖，成交价=(最高买+最低卖)/2 |
| 定价 S1 | `computePressure()` | 净买压力 = (买量-卖量)/(买量+卖量+1) ∈ (-1, 1)，**不再无限大** |
| 定价 S2 | `computeDrift()` | 幸福度/碳排改为**长期趋势偏置**，不再直接乘理论价；碳排用**对数压缩**消除早饱和 |
| 定价 S3 | `computePrice()` | 成交价加权 + 未成交平盘 + ±limitPct 硬限幅 |
| K 线 | `buildCandle()` | 开盘/收盘 + 理论价投影影线 + 确定性盘中波动（上下影线） |
| 做市商 | `stock.service.ts` | 深度与总股本挂钩（`mmDepthPct`），三档上下挂单 |
| 连续封板干预 | `stock.service.ts` | 回归锚模式（`interventionMode=regression`），不再砸盘/托市导致锯齿 |

**可配置参数**（`StockConfig`，比赛级，默认值经调优）全部可在「股票管理 → 推进轮次」对话框修改并随请求提交。

## 2. 撮合与定价核心公式

### 2.1 撮合 `computeMatch()`

```typescript
// engine.ts:31-47
const buys = orders.filter(o => o.side === "BUY");
const sells = orders.filter(o => o.side === "SELL");
const highestBuy = buys.length ? Math.max(...buys.map(o => o.price)) : 0;
const lowestSell = sells.length ? Math.min(...sells.map(o => o.price)) : Infinity;
const totalBuyQty = buys.reduce((s, o) => s + o.quantity, 0);
const totalSellQty = sells.reduce((s, o) => s + o.quantity, 0);
const matched = buys.length > 0 && sells.length > 0 && highestBuy >= lowestSell;
const tradePrice = matched ? (highestBuy + lowestSell) / 2 : null;
```

**结果语义**：

| 字段 | 含义 |
|------|------|
| `highestBuy` / `lowestSell` | 最高买价 / 最低卖价（对手盘边界） |
| `totalBuyQty` / `totalSellQty` | 买 / 卖总股数（不是金额，定价 S1 用「量」而非「金额」） |
| `matched` | 是否存在至少一档可成交（最高买 ≥ 最低卖） |
| `tradePrice` | 成交价 = 买卖边界的中点；不成交为 null |

### 2.2 净买压力 S1：`computePressure()`

```typescript
// 买量-卖量 相对总量占比，分母 +1 防除零
// ∈ (-1, 1)：全部买 → 趋近 +1；全部卖 → 趋近 -1；均衡 → 0
export function computePressure(buyQty: number, sellQty: number): number {
  const denom = buyQty + sellQty + 1;
  return (buyQty - sellQty) / denom;
}
```

**改进效果**：
- 旧公式：金额比 `买盘金额 / 卖盘金额` → 单边 ∞ 或 0 → 直接封板；
- 新公式：净买压力始终被**压缩在 (-1, 1)** 区间，单边行情也只是接近边界，不会无穷大；
- 结合 `maxMovePct=0.05`（默认），即使纯单边，理论价相对上轮收盘也只移动 **±5%**，留给涨跌停硬限幅 ±10% 作为极端边界。

### 2.3 趋势偏置 S2：`computeDrift()` + `computeCarbonDrift()`

```typescript
// 碳排趋势偏置（对数压缩）：
// R = carbonSaturateRatio（默认 2）
// c ∈ (-∞, 1]：碳排=均值→0；碳排=R×均值→-1；碳排≤0→+1
export function computeCarbonDrift(
  currentCarbon: number, industryAvgCarbon: number, carbonSaturateRatio = 2
): number {
  if (industryAvgCarbon <= 0) return 0;
  if (currentCarbon <= 0) return 1;
  const r = currentCarbon / industryAvgCarbon;
  const k = Math.log(carbonSaturateRatio > 1 ? carbonSaturateRatio : 2);
  return Math.min(1, -Math.log(r) / k);
}

// 合成趋势偏置：幸福度+碳排 两个分量分别 × 影响系数后相加
// 均衡盘 drift ≈ 0 → 价格基本持平
export function computeDrift(
  happiness: number, currentCarbon: number, industryAvgCarbon: number,
  happinessImpact: number, carbonImpact: number, carbonSaturateRatio = 2
): number {
  const h = (happiness - 50) / 50;            // happiness∈[0,100] → h∈[-1,1]
  const c = computeCarbonDrift(currentCarbon, industryAvgCarbon, carbonSaturateRatio);
  return happinessImpact * h + carbonImpact * c;
}
```

**改进效果（与旧公式对比）**：

| 场景 | 旧：幸福因子/碳因子**直乘**理论价 | 新：drift × maxMovePct（默认 0.05） |
|------|-------------------------------|--------------------------------|
| 幸福度 100（满值） | 理论价 × 1.20 → 直接封涨停（+20% > +10% 限幅） | drift = +0.2 → 额外 +0.2×5% = **+1%** |
| 碳排 = 均值一半 | 碳因子 1.25 → 封涨停 | c≈+0.5 → 额外 +0.2×0.5×5% = **+0.5%** |
| 碳排 = 2×均值 | 碳因子 0.5 → 封跌停 | c=-1 → 额外 -0.2×5% = **-1%** |
| 碳排 = 10×均值 | 碳因子 1-0.5×9 = -3.5 → 跌停-350% | c≈-ln(10)/ln(2)≈-3.3？不：min(1,-log(r)/k)，r=10→-log(10)/log(2)≈-3.32，但 min(1, -3.32)=**-3.32**？不对，clamp 到 min(1, ...) 但不 clamp 下界。真实行为：drift 过大被后续 ±limitPct 硬限幅兜底，且碳排越高 c 越负但**对数增长越慢**，不会线性锁死 -1。 |

**关键**：幸福度/碳排不再是「乘数」，而是「±1% 级别的趋势偏置」，买卖均衡时价格基本持平，不会因为运营设置了幸福度偏离 50 就全体股票无条件封板。

### 2.4 理论价 + 成交价加权 S3：`computePrice()`

```typescript
export function computePrice(f: PriceFactors): PriceResult {
  // S1：净买压力
  const pressure = computePressure(f.buyQty, f.sellQty);
  // S2：趋势偏置
  const drift = computeDrift(f.happiness, f.currentCarbon, f.industryAvgCarbon,
    f.config.happinessImpact, f.config.carbonImpact, f.config.carbonSaturateRatio);
  // S3-1：理论价
  const theoretical = computeTheoretical(f.lastClose, pressure, drift, f.config.maxMovePct);
  // 硬限幅边界：±limitPct（默认 ±10%）
  const upper = f.lastClose * (1 + f.config.limitPct);
  const lower = f.lastClose * (1 - f.config.limitPct);

  let final: number;
  let usedTradePrice = false;
  if (f.matched && f.tradePrice != null && Number.isFinite(f.tradePrice)) {
    // 有真实成交：成交价权重 + 理论价权重混合
    const w = f.config.tradePriceWeight;  // 默认 0.7
    const blended = w * f.tradePrice + (1 - w) * theoretical;
    final = clamp(blended, lower, upper);
    usedTradePrice = true;
  } else {
    // 零成交（单边无对手盘）→ 平盘，价格不动！
    final = clamp(f.lastClose, lower, upper);
  }
  final = round2(final);
  return { pressure, drift, theoretical, final, usedTradePrice };
}
```

**三条关键改进**：
1. **成交价参与定价**：默认 70% 成交价 + 30% 理论价 → 价格与真实交易挂钩，K 线收盘价代表市场实际成交水平；
2. **未成交 → 平盘**：`matched=false` 或 `tradePrice=null`（无对手盘、挂「涨停买+跌停卖」但不成交）→ 价格 = 上轮收盘，**不会乱动**；
3. **硬限幅兜底**：所有情况最终都 clamp 到 `[lastClose×(1-limitPct), lastClose×(1+limitPct)]`（默认 ±10%），不会出现数学异常价。

### 2.5 初始价 `computeInitPrice()`

```typescript
// Excel 原始量纲：initNetProfit(万) × 10000 / totalShares(万股) / industryPE
export function computeInitPrice(
  initNetProfit: number, totalShares: number, industryPE: number
): number {
  if (industryPE <= 0 || totalShares <= 0) return 0;
  return Math.round((initNetProfit * 10000) / totalShares / industryPE * 100) / 100;
}
```

> 注意：`industryPE<=0 || totalShares<=0` 会返回 0，后续 `lastClose=0` 会导致 `upper=lower=0`、价格永远锁 0。**创建股票时必须校验这两个字段为正**（stock.service 的创建 DTO 已加验证）。

## 3. K 线构建：`buildCandle()`

```typescript
export function buildCandle(
  open: number, close: number, round: number, theoretical?: number
) {
  const upper = round2(open * 1.1);   // 涨停价
  const lower = round2(open * 0.9);   // 跌停价
  const bodyHigh = Math.max(open, close);
  const bodyLow = Math.min(open, close);

  // ① 理论价投影：盘中价格朝理论价延伸，决定影线方向性
  let high = bodyHigh;
  let low = bodyLow;
  if (theoretical != null && Number.isFinite(theoretical)) {
    const t = Math.min(Math.max(theoretical, lower), upper);
    high = Math.max(high, t);
    low = Math.min(low, t);
  }

  // ② 确定性盘中波动：在实体/理论价外叠加影线，避免「光头光脚」
  const wick = (upper - lower) * 0.12;   // 约开盘价的 2.4%
  const upWick = wick * candleNoise(round, open);      // 确定性伪随机
  const downWick = wick * candleNoise(round * 3 + 7, open);
  high = round2(Math.min(upper, high + upWick));
  low  = round2(Math.max(lower, low - downWick));

  const changePct = open !== 0 ? Math.round(((close - open) / open) * 100 * 100) / 100 : 0;
  return { round, open, high, low, close, changePct };
}
```

**设计意图**：
- **开盘 = 上轮收盘**；**收盘 = 本轮最终价**（已限幅）；
- 影线围绕「开盘 → 理论价 → 收盘」路径，加入确定性伪随机的上下影线（`candleNoise` 由 round+open 唯一种子派生，结果可复现）；
- 所有价位限幅在 ±10% 内，涨跌幅 = (收盘-开盘)/开盘。

## 4. 比赛级配置表（`StockConfig` + `DEFAULT_STOCK_CONFIG`）

```typescript
export interface StockConfig {
  limitPct: number;              // 涨跌停硬限幅（±比例），默认 0.10
  maxMovePct: number;            // 单轮价格相对买卖压力的最大移动，默认 0.05
  happinessImpact: number;       // 幸福度趋势偏置强度，默认 0.2
  carbonImpact: number;          // 碳排趋势偏置强度，默认 0.2
  mmDepthPct: number;            // 做市商单档深度占总股本比例，默认 0.001
  mmMinQty: number;              // 单档深度下限（股），默认 1000
  mmMaxQty: number;              // 单档深度上限（股），默认 100000
  mmSpreadPct: number;           // 做市商基准点差（比例），默认 0.02
  interventionMode: "regression" | "expand-limit";  // 连续封板干预模式，默认 regression
  regressionPct: number;         // 回归锚干预价格偏移，默认 0.02
  tradePriceWeight: number;      // 最终价中成交价的权重，默认 0.7
  carbonSaturateRatio: number;   // 碳排对数压缩锚点 R，默认 2
}
```

**全部参数可配置**：创建股票时可传入 `stockConfig`（部分字段覆盖默认），推进轮次对话框也可修改做市商参数（`mmEnabled/mmSpreadPct/mmLevels/mmBaseQuantity` 等做市商专属）。

## 5. 做市商实现（`stock.service.ts`）

### 5.1 流动性深度与总股本挂钩

```
单档深度 qty = clamp(totalShares * 10000 * mmDepthPct, mmMinQty, mmMaxQty)
```

- 总股本 100 万股（totalShares=100，单位是万股）：
  - qty = clamp(100×10000×0.001, 1000, 100000) = clamp(1000, 1000, 100000) = **1000 股/档**
- 总股本 5000 万股：
  - qty = clamp(5000×10000×0.001, 1000, 100000) = clamp(50000, 1000, 100000) = **50000 股/档**

不再是固定 1000 股，小盘股深度小、大盘股深度大，流动性与市值匹配。

### 5.2 常规三档挂单

以当前价 `P` 为基准，`spreadPct=2%`、`levels=3`：

| 方向 | 档位 1 | 档位 2 | 档位 3 |
|------|--------|--------|--------|
| 卖 | P×1.02，qty 股 | P×1.04，qty×2 股 | P×1.06，qty×3 股 |
| 买 | P×0.98，金额对称 | P×0.96，金额对称 | P×0.94，金额对称 |

推进前：取消上轮做市商所有未成交 PENDING 单（全部 CANCELLED），再挂新一轮。

## 6. 连续封板干预（回归锚模式，默认 `interventionMode=regression`）

### 触发条件：最近 3 根 K 线中**连续涨停 ≥ 2 轮**（或跌停同理）。

### 旧模式（已废弃）：砸盘/托市 → 锯齿振荡
- 涨停后挂「涨停价 × 10 倍量」大卖单 → 当轮直接跌停 → 下一轮封板 → 干预跌停 → 当轮直接涨停。

### 新模式（已实现，`regressionPct=0.02`）：引导回归，不反向封板

```
连续涨停 ≥ 2 轮：
  · 回归锚价 = 上轮收盘 × (1 - regressionPct)  → 即「当前价回落 2%」
  · 在回归锚价挂 2×qty 的卖单 → 吸收上方买压，引导价格向回归锚靠拢
  · 不在涨停价挂天量单（避免直接砸跌停）

连续跌停 ≥ 2 轮：
  · 回归锚价 = 上轮收盘 × (1 + regressionPct)  → 即「当前价回升 2%」
  · 在回归锚价挂 2×qty 的买单 → 托住下方卖压，引导回归
```

**效果**：干预不再是「猛砸/猛托」，而是「小幅回归锚」，价格会在 2~3 轮内逐步从极端行情回到均衡区间，**不再出现 涨停→干预→跌停** 的锯齿振荡。

## 7. 推进轮次流程（`advanceRound`，`stock.service.ts`）

```
对每只股票：
  1. applyPbRound(stock)
     · PE 联动刷新（如果配置了行业 PE 变动）
     · 小概率随机 ±2% 基础游走（不超 limitPct）
  2. generateMarketMakerOrders(stock, mmConfig)
     · 建仓补仓单（持仓不足直接买入写入持仓+扣现金）
     · 常规三档买卖挂单（深度×股本）
     · 连续封板干预回归单（若触发）
     · 上轮未成交旧单全部置 CANCELLED
  3. advanceOneStock(stock)
     · 汇总全部 PENDING 订单（玩家 + 做市商）
     · computeMatch() → 撮合 tradePrice
     · computePrice() → 算出 final 收盘价
     · 撮合循环：按买价降序、卖价升序，逐档成交并划转资金/持仓
     · 订单状态：FILLED / PARTIAL / PENDING
     · buildCandle() → 写入 StockCandle K 线记录
     · 更新 Stock.currentPrice + currentRound
  4. 广播 stock:round-advanced → 客户端实时刷新行情
```

## 8. 典型行情行为（验证用例）

| 场景 | 旧引擎行为 | 新引擎行为 |
|------|-----------|-----------|
| 幸福度=100，买卖均衡 (qty 1:1) | 理论价×1.20 → **涨停** | pressure=0, drift=+0.2 → 理论价=上轮×(1+0+0.01)=+1% → 收盘≈+1%（不封板） |
| 纯买单 1000 股，无卖单 | ratio=∞ → **涨停** | pressure=(1000-0)/1001≈+0.999 → 理论价≈上轮×(1+0.999×0.05)=+4.995% → 但 matched=false → **平盘**（无对手盘不动价） |
| 买 1000 vs 卖 200（金额比 5:1，量比 5:1） | ratio=5 → 理论价×5 → **涨停** | pressure=(1000-200)/1201≈+0.666 → 理论价≈+3.33% → 若有真实成交，再按成交价加权收盘≈+2~3%（正常波动） |
| 连续 2 轮涨停 → 干预 | 干预挂涨停价 10 倍卖单 → **当轮跌停** → 锯齿 | 回归锚×0.98 挂 2×qty 卖单 → 当轮回落 1~3% → 逐步回归均衡 |
| 挂涨停价买单 + 跌停价卖单（不成交） | 金额比计算可能仍然动价 → 乱跳 | matched=false → final=lastClose → **平盘不动** |

## 9. 调优指南

默认参数已针对「消除一字板 + 正常供需波动 + 不极端行情」调优。如需针对特定比赛风格调整：

| 参数 | 调大的效果 | 调小的效果 |
|------|-----------|-----------|
| `limitPct`（±涨跌停硬限，0.10） | 波动范围更大（如 0.20=±20%） | 价格更稳定（如 0.05=±5%，但会更频繁触碰边界） |
| `maxMovePct`（压力最大移动，0.05） | 相同买卖压力下价格波动更剧烈（如 0.08） | 更不敏感（如 0.02，几乎横盘） |
| `happinessImpact`（幸福度权重，0.2） | 幸福度对价格影响更大 | 幸福度几乎不影响 |
| `carbonImpact`（碳排权重，0.2） | 碳排对价格影响更大 | 碳排几乎不影响 |
| `tradePriceWeight`（成交价权重，0.7） | 定价更贴近真实成交价（0.9） | 定价更贴近理论价供需模型（0.3） |
| `mmDepthPct`（做市商深度，0.001） | 流动性更足，大单不易封板 | 深度浅，容易封板但更真实 |
| `regressionPct`（干预回归幅度，0.02） | 快速拉回均衡（0.05） | 缓慢回归（0.01，可能多封几轮） |
| `carbonSaturateRatio`（碳排压缩锚，2） | 碳排越不容易饱和（R=3：3×均值才 c=-1） | 更早饱和（R=1.5，但必须 >1） |
