# 仪表盘自定义控件开发指南

仪表盘内置了三种控件（文字 / 仪表 / 表格）。除此之外，你**无需改动框架代码**，只需写一个 Vue 组件并在注册入口登记，就能把任意自定义控件加入仪表盘的「添加控件」菜单，并自动获得拖拽、缩放、编辑外壳。

本指南面向需要自行设计控件的开发者。读完即可独立创建、配置、上架一个控件。

---

## 1. 快速开始（3 步）

**第 1 步：写控件组件**

在 `client/src/components/dashboard/widgets/` 下新建一个 SFC，例如 `MyWidget.vue`，声明以下三个 props：

```vue
<script setup lang="ts">
import type { CustomWidgetProps } from "../types";

const props = defineProps<CustomWidgetProps>();
// props.widget  —— 本控件的完整配置（含 config.custom）
// props.value   —— 若绑定了字段，为字段当前值；否则 undefined
// props.totalValue —— 若绑定了总量字段，为总量当前值；否则 undefined
</script>

<template>
  <div>在这里用 props.widget / props.value 渲染你想要的内容</div>
</template>
```

**第 2 步：注册**

打开 `client/src/components/dashboard/registerCustomWidgets.ts`，import 你的组件并调用 `registerCustomWidget`：

```ts
import MyWidget from "./widgets/MyWidget.vue";
import { registerCustomWidget } from "./types";

registerCustomWidget({
  type: "my-widget",
  label: "我的控件",
  component: MyWidget,
  defaultSize: { w: 220, h: 160 },
  bindable: false,
  defaultConfig: { /* 创建时写入 config.custom 的默认值 */ },
});
```

**第 3 步：使用**

重新构建 / 热更新前端后，进入仪表盘，点击右下角 `＋`，菜单底部「自定义控件」分组下会出现「我的控件」。点击即可添加到画布，并可在编辑对话框中调整。

> 注册入口 `registerCustomWidgets.ts` 已在 `main.ts` 中 `app.mount` 之前被 import，因此**注册在应用启动前完成**，无需手动刷新。

---

## 2. 注册 API：`registerCustomWidget`

函数签名：

```ts
registerCustomWidget(def: CustomWidgetDef): void
```

`CustomWidgetDef` 字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | `string` | 是 | 控件类型标识，**全局唯一**。会作为 `WidgetConfig.type` 持久化到本地存储。不能与内置类型（`text`/`gauge`/`table`）重名，否则抛错。 |
| `label` | `string` | 是 | 在「添加控件」菜单中显示的名称。 |
| `component` | `Component` | 是 | 渲染组件。必须声明 props：`widget: WidgetConfig; value: unknown; totalValue: unknown`。 |
| `defaultSize` | `{ w: number; h: number }` | 否 | 创建控件时的默认宽高（px）。缺省 `220 × 160`。 |
| `bindable` | `boolean` | 否 | 是否允许在编辑对话框中绑定「可查看字段」。`true` 时对话框出现绑定下拉，组件经 `props.value` 读取字段当前值；`false`（默认）时控件仅依赖 `config.custom` 自行取数。 |
| `description` | `string` | 否 | 一句话说明，显示在编辑对话框中。 |
| `defaultConfig` | `Record<string, unknown>` | 否 | 创建控件时写入 `config.custom` 的默认值（必须是 JSON 可序列化对象）。用户可在编辑对话框修改。 |

重复注册同名 `type` 会**覆盖**前者；与内置类型冲突或被注册为空白 `type` / `label` / `component` 会**抛错**。

其他可用导出（按需）：

- `getCustomWidget(type)` → 取某个控件定义，非自定义 / 未注册返回 `undefined`。
- `listCustomWidgets()` → 列出所有已注册自定义控件（添加菜单内部已用到）。
- `isCustomType(type)` / `isBuiltinType(type)` → 判断类型归属。

## 3. 控件组件 Props 契约

自定义组件**必须**声明以下三个 props（名称、类型一致）：

```ts
interface CustomWidgetProps {
  widget: WidgetConfig;     // 本控件完整配置
  value: unknown;           // 绑定字段的当前值（bindable 且已绑定时才有意义）
  totalValue: unknown;      // 绑定总量字段的当前值
}
```

- `widget.config.custom` 是你自己的配置对象（`Record<string, unknown>`）。读取时建议做类型兜底，例如：

  ```ts
  const step = computed(() => Number((props.widget.config.custom as any)?.step ?? 1));
  ```

- 控件只负责**渲染**。拖拽、缩放、选中、删除、持久化全部由外壳 `DashboardWidget.vue` 处理，你无需关心。
- 控件尺寸由外壳的 `w` / `h` 决定，组件根元素建议 `width:100%; height:100%` 自适应填满。

---

## 4. 字段绑定（`bindable`）

把 `bindable` 设为 `true` 后，编辑对话框会显示「绑定字段」下拉，列举当前比赛下所有**可查看字段**（区域总览卡片、公司产业字段、消费者需求）。用户选定后：

- 该字段的实时值通过 `props.value` 传给组件；
- 总量字段（如有）通过 `props.totalValue` 传入；
- 字段值随后台数据变化自动刷新（框架已接入实时监听）。

适合场景：把「某区域某产品的消费者需求数量」「某公司的某个产业字段」直接画成你自定义的图表。

若 `bindable: false`，组件应自行取数（例如在你的代码里调用 API，或完全依赖静态的 `config.custom`）。

---

## 5. 自定义配置 `config.custom`

`config.custom` 是任意 JSON 可序列化对象，由你的控件自行解释。它有两个来源：

1. **默认值**：注册时通过 `defaultConfig` 提供，创建控件时自动写入。
2. **用户修改**：编辑对话框提供「自定义配置 (JSON)」文本框，用户手动编辑并保存。保存时会做 JSON 合法性校验（必须是对象，非对象 / 非法 JSON 会提示且不会保存）。

读取示例：

```ts
const cfg = (props.widget.config.custom ?? {}) as Record<string, unknown>;
const color = (cfg.color as string) || "#409eff";
```

保存后的 `config.custom` 随仪表盘布局一起按「账号 + 比赛」隔离存储在 `localStorage`，无需你处理持久化。

## 6. 示例控件解读

原先自带的示例「计数卡」（`ExampleCounterWidget`）已于 2026-08-13 移除。注册入口 `registerCustomWidgets.ts` 保留了注册骨架，供你追加自己的控件。

示例控件演示了「读绑定字段 + 读自定义配置」两件事：

- 用 `props.value` 拿绑定字段当前值；
- 用 `props.widget.config.custom` 拿自定义配置；
- 在 `widgets/` 目录下新建 SFC 组件即可。

你可以直接参考注册入口中的注释模板改写。

## 7. 删除 / 替换控件

- **临时下架**：在 `registerCustomWidgets.ts` 里删掉对应 `registerCustomWidget(...)` 调用，重新构建即可。已存在于某用户仪表盘中的该类型控件会显示为「未知控件」占位（不会崩溃），删除该控件即可。
- **彻底替换**：保持 `type` 不变、换 `component` 即可平滑替换；若同时改了 `config.custom` 结构，旧数据字段缺失时请在你组件里做好默认值兜底。
- **改 `type` 名**：等价于新增控件，旧布局里按旧 `type` 存储的控件会变为「未知控件」，需要用户手动删除。

---

## 8. 注意事项

1. **注册时机**：必须在 `app.mount` 之前完成（当前 `main.ts` 已保证）。若你改了 `main.ts` 的 import 顺序，请确保 `import "./components/dashboard/registerCustomWidgets"` 在 `app.mount("#app")` 之前。
2. **类型唯一**：`type` 不要与内置控件重名，也不要与别人的控件重名，否则后注册的覆盖先注册的。
3. **`config.custom` 必须可序列化**：存进 `localStorage` 前会 `JSON.stringify`，函数、class 实例、循环引用等会丢失或报错。
4. **JSON 校验**：编辑对话框保存自定义配置时强制校验为 JSON 对象，非法输入不会写入。
5. **权限**：自定义控件与内置控件一样，仅在仪表盘内展示。如果控件的 `config.custom` 里想引用受权限保护的数据，请通过 `bindable` 走框架的字段绑定（已受权限约束），不要自行绕过权限拉取敏感数据。
6. **样式隔离**：组件使用 `<style scoped>`，不影响其他控件；若需覆盖仪表盘外壳样式，请限定在自己组件根类名下。

## 9. 文件索引

| 文件 | 作用 |
| --- | --- |
| `client/src/components/dashboard/types.ts` | 注册 API、类型定义（`CustomWidgetDef` / `CustomWidgetProps` / `registerCustomWidget` 等） |
| `client/src/components/dashboard/registerCustomWidgets.ts` | **你主要编辑这里**：登记自定义控件（`widgets/` 目录需自行创建） |
| `client/src/components/dashboard/widgets/*.vue` | 你的控件组件所在目录（需自行创建） |
| `client/src/components/dashboard/DashboardWidget.vue` | 渲染外壳（已支持自定义分支，一般无需改） |
| `client/src/views/dashboard/DashboardView.vue` | 添加菜单 / 编辑对话框（已支持自定义，一般无需改） |
| `client/src/main.ts` | 注册入口的 import 挂载点 |
