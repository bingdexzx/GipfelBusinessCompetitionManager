# 仪表盘自定义控件开发指南

> 代码基线：`client/src/components/dashboard/*`、`client/src/views/dashboard/DashboardView.vue`
>
> 仪表盘内置三种控件（文字 / 仪表 / 表格）。除此之外你**无需改动框架代码**，只需写一个 Vue 组件并在注册入口登记，就能把任意自定义控件加入仪表盘的「添加控件」菜单，并自动获得拖拽、缩放、编辑外壳、本地持久化四套能力。
>
> 读完本指南即可独立创建、配置、上架一个自定义控件。

---

## 1. 快速开始（3 步）

**第 1 步：写控件组件**

在 `client/src/components/dashboard/widgets/` 下新建一个 SFC（你也可以放在任何地方，只要能被 import 到），声明以下三个 props：

```vue
<script setup lang="ts">
import type { CustomWidgetProps } from "../types";

const props = defineProps<CustomWidgetProps>();
// props.widget      —— 本控件的完整配置（含 config.custom）
// props.value       —— 若在编辑对话框中绑定了「可查看字段」，为字段当前值；否则 undefined
// props.totalValue  —— 若绑定了「总量字段」，为总量当前值；否则 undefined
</script>

<template>
  <div class="my-widget">
    <div>在这里用 props.widget / props.value 渲染你想要的内容。</div>
  </div>
</template>

<style scoped>
/* 样式建议见 §4；仪表盘本身是深色背景，控件不需要画边框 */
</style>
```

**第 2 步：注册**

打开 `client/src/components/dashboard/registerCustomWidgets.ts`，import 你的组件并调用 `registerCustomWidget`：

```ts
import MyWidget from "./widgets/MyWidget.vue";
import { registerCustomWidget } from "./types";

registerCustomWidget({
  type: "my-widget",               // 控件类型标识（全局唯一），会持久化到本地存储
  label: "我的控件",                // 「添加控件」菜单中显示的名称
  component: MyWidget,             // 渲染组件（即你写的 SFC）
  defaultSize: { w: 220, h: 160 }, // 默认宽高（px，可缺省，默认 220×160）
  bindable: false,                 // 是否允许在编辑对话框里绑定「可查看字段」
  description: "一句话说明（可选，显示在编辑对话框）",
  defaultConfig: {                 // 创建控件时写入 config.custom 的默认值（JSON 可序列化）
    theme: "dark",
    digits: 1,
  },
});
```

**第 3 步：使用**

重新构建 / 热更新前端后，进入仪表盘，点击右下角 `＋`，菜单底部**「自定义控件」分组**下会出现「我的控件」。点击即可添加到画布，并可在编辑对话框中调整。

> 注册入口 `registerCustomWidgets.ts` 已在 [client/src/main.ts](file:///c:/Users/32394/Desktop/GipfelBusinessCompetitionManager/client/src/main.ts) 中 `app.mount` 之前被 import，因此**注册在应用启动前完成**，无需手动刷新。

## 2. 注册 API：`registerCustomWidget(def: CustomWidgetDef): void`

`CustomWidgetDef` 全字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `type` | `string` | ✅ | 控件类型标识，**全局唯一**。会作为 `WidgetConfig.type` 持久化到本地存储。不能与内置类型（`text` / `gauge` / `table`）重名，否则抛错。 |
| `label` | `string` | ✅ | 在「添加控件」菜单中显示的名称。 |
| `component` | `Component` | ✅ | 渲染组件。必须声明 props：`widget`、`value`、`totalValue`（详见 §3）。 |
| `defaultSize` | `{ w: number; h: number }` | — | 创建控件时的默认宽高（px）。缺省：`{ w: 220, h: 160 }`。宽高在画布上会被 20px 网格吸附（GRID=20），建议用 20 的倍数避免抖动。 |
| `bindable` | `boolean` | — | 是否允许在编辑对话框中绑定「可查看字段」。`true` 时对话框出现「绑定字段」+「绑定总量字段」两组下拉，组件经 `props.value` / `props.totalValue` 读取字段当前值。`false`（默认）时控件仅依赖 `config.custom` 自行取数。 |
| `description` | `string` | — | 一句话说明，显示在编辑对话框顶部。 |
| `defaultConfig` | `Record<string, unknown>` | — | 创建控件时写入 `config.custom` 的默认值。**必须是 JSON 可序列化对象**（函数 / Set / Map 不行）。用户可在编辑对话框的「自定义配置 (JSON)」块中查看 / 修改。 |

**注册边界条件**：
- 重复注册同名 `type` 会**覆盖**前者（便于开发时热替换）
- 与内置类型冲突或空白 `type` / `label` / `component` 会**抛错**（启动阶段可见）

其他可用导出（按需）：
- `getCustomWidget(type) → CustomWidgetDef \| undefined` — 按 type 取定义
- `listCustomWidgets() → CustomWidgetDef[]` — 列出所有已注册（「添加控件」菜单内部已用）
- `isCustomType(type) / isBuiltinType(type) → boolean` — 判断类型归属

## 3. 控件组件 Props 契约

自定义组件**必须**声明以下三个 props（名称、类型一致）：

```ts
interface CustomWidgetProps {
  widget: WidgetConfig;     // 本控件完整配置
  value: unknown;           // 绑定字段的当前值（bindable 且已绑定时才有意义）
  totalValue: unknown;      // 绑定总量字段的当前值
}
```

### 3.1 `widget` 结构速查

```ts
interface WidgetConfig {
  id: string;                                          // 控件唯一 ID（创建时生成 w-${Date.now()}-${rand}）
  type: WidgetType;                                    // 你注册的 type
  x: number; y: number; w: number; h: number;          // 画布位置 / 尺寸（px，网格吸附）
  config: {
    caption?: string;        // 标题（编辑对话框通用字段，对自定义控件同样可用）
    fieldRef?: FieldRef;     // 若 bindable=true，用户选择的「可查看字段」引用
    totalField?: FieldRef;   // 选择的「总量字段」引用
    custom?: Record<string, unknown>;  // ✅ 你的自定义配置对象（defaultConfig + 用户在 JSON 块里修改的结果）
  };
}
```

### 3.2 `value` / `totalValue` 的来源与刷新

- `value = DashboardView 根据 widget.config.fieldRef 实时解析出的字段当前值`
- `totalValue = DashboardView 根据 widget.config.totalField 实时解析出的字段当前值`
- 字段值**随仪表盘数据刷新周期自动更新**（通常 5s 轮询 + WebSocket 推送合并，组件无需手动订阅）
- 未绑定或字段不存在 → `undefined`

### 3.3 读取 `config.custom` 的稳健写法

`custom` 是 `Record<string, unknown>`，读取时务必做类型兜底：

```ts
// ✅ 推荐：用一个 reactive 对象做解构 + 默认值
import { computed } from "vue";
const cfg = computed(() => ({
  theme:  (props.widget.config.custom?.theme as string)  ?? "dark",
  digits: (props.widget.config.custom?.digits as number) ?? 1,
  unit:   (props.widget.config.custom?.unit as string)   ?? "元",
}));
```

不要写成 `custom.theme`（TS 会报错，运行时如果 custom 是旧数据 undefined 也会炸）。

### 3.4 控件内主动持久化「小改动」（少见）

绝大多数自定义配置**走编辑对话框的 JSON 编辑器修改**并由框架落盘，这是推荐路径。

如果你确实要在控件 UI 内部加一个按钮改点配置并立即保存，可触发自定义事件 `update:custom`（框架层**没有**内建监听这个事件；需要你在自定义控件内直接调 `patch` 的话，请先查看 DashboardWidget 对外暴露的 patch 事件。当前推荐做法：把「需要用户交互改的状态」也放在 custom 内，**让用户通过 JSON 编辑器改**，或在控件内使用浏览器本地 `localStorage` 单独存（非持久化到仪表盘配置）。

## 4. 样式规范（与仪表盘视觉协调）

仪表盘画布背景是**深色**，控件外层有白色描边 + 半透明背景。自定义控件样式建议：

```vue
<template>
  <!-- 最外层不要加额外的 border / background，不要给 root 加固定宽高 -->
  <div class="mom-card" :class="`theme-${cfg.theme}`">
    <header class="mom-card__cap">{{ widget.config.caption || "标题" }}</header>
    <div class="mom-card__body">
      <span class="mom-card__num">{{ display }}</span>
      <span class="mom-card__unit">{{ cfg.unit }}</span>
    </div>
  </div>
</template>

<style scoped>
/* 推荐用 CSS 变量承接仪表盘主题：前景/背景/主色/辅色 */
.mom-card {
  width: 100%;
  height: 100%;
  padding: 12px 14px;
  box-sizing: border-box;
  color: #1f2937;            /* 深色画布下，组件内用浅色文字 */
  display: flex;
  flex-direction: column;
  gap: 6px;
  user-select: none;         /* 避免拖拽选中文本 */
  -webkit-user-drag: none;
}
.mom-card__cap {
  font-size: 12px;
  opacity: 0.75;
  letter-spacing: 0.05em;
}
.mom-card__body {
  display: flex;
  align-items: baseline;
  gap: 4px;
  flex: 1;
}
.mom-card__num {
  font-size: 28px;
  font-weight: 600;
  font-variant-numeric: tabular-nums;  /* 数字等宽，避免跳动 */
}
.mom-card__unit { opacity: 0.7; font-size: 12px; }
</style>
```

**避坑清单**：
- ❌ 不要给控件根节点加 `position: fixed / absolute`（框架自身就用绝对定位 + 拖拽）
- ❌ 不要加 `width: 100vw / height: 100vh`（控件尺寸由 w/h 控制，响应式用 `width:100%; height:100%`）
- ❌ 不要监听全局 `pointerdown`（会和画布拖拽 / 缩放冲突）；在控件内部按需监听即可
- ✅ 用 CSS 变量 / 深色优先；避免纯白色大面积背景（会在深色画布上刺眼）

## 5. 自行取数 & 实时刷新（bindable=false 场景）

`bindable=false` 的控件（如 K 线图 / TopN 排名 / 自定义聚合卡片）需要自己取数据。推荐两条路径：

### 5.1 路径 A：直接 import API 层 + 手动刷新

```vue
<script setup lang="ts">
import { ref, onMounted, onBeforeUnmount } from "vue";
import { companyApi } from "@/api/companies";           // 示例：你的 API 模块
import { useResourceChanged } from "@/hooks/useResourceChanged";

const props = defineProps<CustomWidgetProps>();
const rows = ref<{ name: string; revenue: number }[]>([]);

async function reload() {
  // widget.config.custom 里可放「limit」「industryFilter」等参数
  const limit = (props.widget.config.custom?.limit as number) ?? 5;
  const res = await companyApi.getTopRevenue({ limit });  // 伪代码
  rows.value = res ?? [];
}

let timer: number | undefined;
onMounted(async () => {
  await reload();
  timer = window.setInterval(reload, 15_000);             // 兜底 15s 轮询
});

// 🔔 接收全局资源变更广播（更精细，不必等下一次轮询）
useResourceChanged({ scope: "competition" }, (evt) => {
  if (evt.resource === "company" || evt.resource === "company-field") {
    void reload();
  }
});

onBeforeUnmount(() => { if (timer) clearInterval(timer); });
</script>
```

### 5.2 路径 B：复用仪表盘的「已绑定字段机制」（bindable=true）

如果控件核心是「展示一个字段 + 装饰」，直接走 bindable=true：无需自己发请求，框架会把字段当前值塞进 `props.value`。

**如何选择**：
- 控件只是「展示 1~2 个字段」的包装 → 选 bindable=true
- 控件要聚合、TopN、查多表、画 K 线 → 选 bindable=false + 5.1 自行取数

## 6. 编辑对话框的「自定义配置 (JSON)」块

当用户双击控件或点击 ✎ 打开编辑对话框时：

- 所有控件：通用 `caption` 字段 + 位置 / 宽高数字输入
- bindable=true 的控件：额外出现「绑定字段」+「绑定总量字段」下拉
- **所有自定义控件**：对话框底部出现**「自定义配置 (JSON)」代码块**，展示当前 `widget.config.custom` 的 JSON，用户可直接编辑 → 保存时写回 `custom` → 控件下次渲染拿到新值

**JSON 编辑器特性**：
- 语法校验（保存前）：JSON 格式错误 → 保存按钮禁用 + 错误行提示
- 初始化：来自你注册时的 `defaultConfig`

**最佳实践**：把你自定义控件的所有「可配置项」都收敛到 custom 的扁平 key 里（不要用深层嵌套 > 3 层，最终用户编辑 JSON 不友好），并在 `description` 字段里写明：

```ts
registerCustomWidget({
  type: "mom-card",
  label: "同比卡片",
  component: MoMCard,
  bindable: true,
  description: `配置项：digits=小数位, unit=单位, positiveGreen=true/false（上涨绿/涨红）`,
  defaultConfig: { digits: 1, unit: "元", positiveGreen: true },
});
```

## 7. 完整示例：「同比环比卡」控件

### 7.1 组件：`widgets/MoMCard.vue`

```vue
<script setup lang="ts">
import { computed } from "vue";
import type { CustomWidgetProps } from "../types";

const props = defineProps<CustomWidgetProps>();

// 解析 custom 配置，给每个字段加默认值
const cfg = computed(() => ({
  digits:        (props.widget.config.custom?.digits as number) ?? 1,
  unit:          (props.widget.config.custom?.unit as string)   ?? "",
  positiveGreen: (props.widget.config.custom?.positiveGreen as boolean) ?? true,
}));

// 当前值 = props.value（来自用户绑定的字段）
const current = computed(() => Number(props.value) || 0);

// 这里为演示做简化：同比从 config.custom.lastPeriodValue 读
// 实际项目中可改成：从 totalValue / 或组件内额外查询历史值
const last = computed(() => Number(props.widget.config.custom?.lastPeriodValue) || 0);

const diff = computed(() => current.value - last.value);
const momPct = computed(() =>
  last.value === 0 ? 0 : (diff.value / Math.abs(last.value)) * 100
);

const positive = computed(() => diff.value >= 0);
const trendColor = computed(() => {
  const green = cfg.value.positiveGreen;
  return positive.value ? (green ? "#10b981" : "#ef4444")
                        : (green ? "#ef4444" : "#10b981");
});
</script>

<template>
  <div class="mom">
    <div class="mom-cap">{{ widget.config.caption || "销售额" }}</div>
    <div class="mom-now">
      <span class="mom-num">{{ current.toFixed(cfg.digits) }}</span>
      <span v-if="cfg.unit" class="mom-unit">{{ cfg.unit }}</span>
    </div>
    <div class="mom-diff" :style="{ color: trendColor }">
      <span>{{ positive ? "▲" : "▼" }}</span>
      <span>{{ Math.abs(diff).toFixed(cfg.digits) }}{{ cfg.unit }}　</span>
      <span>{{ (positive ? "+" : "") + momPct.toFixed(1) }}%</span>
    </div>
  </div>
</template>

<style scoped>
.mom { width:100%; height:100%; padding:12px 14px; box-sizing:border-box;
       display:flex; flex-direction:column; gap:6px; color:#1f2937; }
.mom-cap { font-size:12px; opacity:.7; letter-spacing:.05em; }
.mom-now { display:flex; align-items:baseline; gap:4px; flex:1; }
.mom-num { font-size:30px; font-weight:700; font-variant-numeric: tabular-nums; }
.mom-unit { font-size:13px; opacity:.75; }
.mom-diff { font-size:13px; font-weight:600; font-variant-numeric: tabular-nums; }
</style>
```

### 7.2 注册：`registerCustomWidgets.ts` 追加

```ts
import MoMCard from "./widgets/MoMCard.vue";

registerCustomWidget({
  type: "mom-card",
  label: "同比环比卡",
  component: MoMCard,
  defaultSize: { w: 200, h: 140 },
  bindable: true,
  description:
    "展示一个字段的当前值 + 差值 + 同比百分比。" +
    "自定义 JSON 配置：digits 小数位 / unit 单位 / positiveGreen 涨跌配色方向 / lastPeriodValue 上期值",
  defaultConfig: {
    digits: 1,
    unit: "元",
    positiveGreen: true,
    lastPeriodValue: 0,
  },
});
```

### 7.3 使用

1. 打开仪表盘 → 右下角「＋」→「自定义控件」分组 → 点击「同比环比卡」
2. 双击卡 → 编辑对话框：
   - Caption（标题）填入「本季营收」
   - 绑定字段选择「公司 → 营业收入」
   - 自定义 JSON 把 `lastPeriodValue` 改成上期实际值（或改为从组件内查询，按需扩展）
3. 保存，画布上卡立刻按新字段刷新。

## 8. 常见问题 & 避坑

### Q1：注册时报 `类型 "xxx" 与内置控件冲突`
A：`text / gauge / table` 是三个保留类型。换一个自定义 type 名字即可（如 `my-text`、`kpi-gauge`）。

### Q2：画布上出现「未知控件」并显示我的 type
A：说明注册**未生效**。检查：
- `registerCustomWidgets.ts` 真的写了 `registerCustomWidget({type:xxx,...})`
- 你的组件在 `main.ts` 之前被 import（正常情况 `registerCustomWidgets.ts` 已经在 main.ts 顶部 import 了，如果你的组件写在 `widgets/` 下但未被 import，就不会被注册）
- type 拼写和存进配置里的完全一致（大小写敏感）

### Q3：`props.value` 一直是 `undefined`
A：按序检查：
1. 注册时 `bindable: true` 了吗？（默认 false）
2. 双击控件 → 编辑对话框 → 真的选了「绑定字段」吗？
3. 字段本身在当前比赛下是否存在值？（空字段同样是 undefined，不是 0 / ""）
4. 前端缓存里是否有该字段数据？打开 DevTools → IndexedDB → `cache-${competitionId}` → `fields` store 看一下键是否存在。

### Q4：`widget.config.custom` 整个是 `undefined`
A：通常是旧数据 / 空配置。在组件里读取加 `?? {}` 兜底：

```ts
const custom = computed(() => props.widget.config.custom ?? {});
const digits = computed(() => (custom.value.digits as number) ?? 1);
```

### Q5：拖拽 / 缩放冲突（控件自己的拖拽抢了画布的拖拽）
A：在你控件内部的可拖拽元素上加 `@pointerdown.stop`（阻止冒泡到外层 `dw-widget`）。不冒泡时，画布拖拽不会响应，控件内部自己处理即可。

### Q6：保存「自定义配置 JSON」时报「JSON 格式错误」
A：在对话框里改的内容必须是合法 JSON：
- key 必须用双引号：`{"digits":1}` 而不是 `{digits:1}`
- 注释不允许（JSON 不支持 `//` 或 `/* */`）
- 字符串必须双引号，不能单引号
- 末尾不允许 trailing comma：`[1, 2, 3,]` → `[1, 2, 3]`

### Q7：如何让自定义控件出现在顶部的「推荐控件」分组？
A：目前框架里「自定义控件」是单独分组，要放到推荐分组需改 `DashboardView.vue` 内部的分组逻辑（超出了「无需改框架代码」的范围）。默认放「自定义控件」分组即可。
