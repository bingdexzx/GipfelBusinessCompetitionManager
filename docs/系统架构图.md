## 3. 服务端请求处理管线

```

                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ① OperatorMiddleware        │  JWT解析(不验签) → AsyncLocalStorage
                 │     operator / requestId / ip│  注入请求上下文, 供后续所有日志使用
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ② securityHeaders           │  CSP / X-Frame-Options / CORP
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ③ loginRateLimiter          │  POST /api/auth/login 专用
                 │     10次/5分钟 → 锁定15分钟   │  IP+用户名维度, 内存计数
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ④ CORS                      │  白名单 / 本地网络反射
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑤ JwtAuthGuard (APP_GUARD)  │  Passport JWT 验证
                 │     @Public() 可跳过          │  + tokenVersion 单设备互斥
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑥ MustChangePasswordGuard   │  mustChangePassword=true 拦截
                 │     (APP_GUARD)              │  仅放行 /auth/change-password, /auth/me
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑦ CompetitionScopeGuard     │  @NoCompetitionScope() 可跳过
                 │     (APP_GUARD)              │  多租户: 校验/注入 competitionId
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑧ OwnershipGuard            │  @Ownership({model}) 装饰时生效
                 │     (APP_GUARD)              │  BOLA防御: 实体.competitionId == 用户.competitionId
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑨ ValidationPipe (全局)     │  whitelist + transform + forbidNonWhitelisted
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑩ PermissionsGuard          │  @RequirePermissions() 装饰时生效
                 │     (路由级)                  │  hasPermission(role, permissions, required)
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  Controller → Service        │  业务逻辑
                 │       │                      │
                 │       ▼                      │
                 │  PrismaService               │
                 │  ├── $allOperations 扩展     │  审计中间件: 记录 before/after/changes
                 │  └── emitResourceChanged()   │  写操作后自动广播 resource:changed
                 └─────────────┬───────────────┘
                               │
                               ▼
                 ┌─────────────────────────────┐
                 │  ⑪ ResponseInterceptor       │  { code:0, message:"成功", data:T }
                 └─────────────┬───────────────┘
                               │

```
