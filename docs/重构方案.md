## 3. 已落地的关键里程碑（与代码一致）

### M1 工程地基 & 纯函数测试基建 ✅
- Jest + ts-jest + @types/jest 配置完成
- 单测覆盖：safe-expression（86 cases 安全矩阵）、stock/engine、catalog、role-templates、json-schema、industry-calc-engine、company-fields
- 验收：`cd server && npm test` 全部通过

### M2 引擎单源化与上帝模块拆分 ✅
- contracts/engine 四文件拆分（values / effects / conditions / compute）+ 编排层瘦身
- common/engine-ops.ts（44 OP 运算 + OP_ARG_SPECS + EXPR_HELPERS + toNumber / isTruthy），两引擎直接引用
- shared/engine-dsl 独立 TS 包（schema.ts / index.ts），build/start 脚本先编译它

### M3 权限全链路（actionRank + 授予上限 + 目录单源 + 单设备踢出） ✅
- catalog.ts：19 域 41 key，每个 key 带 actionRank；hasPermission → rank ≥ 比较
- role-templates.ts：SUPER_ADMIN / COMPETITION_ADMIN / OPERATION / SPECTATOR 四模板 + GRANT_CEILINGS
- users.service：授予上限 assertGrantAllowed，越权直接 403
- JWT 载荷 `tv` + DB `tokenVersion`：改密/登出/管理员踢出 → tokenVersion++ → 旧 token 全部失效
- 前端：authStore.fetchPermissionCatalog 从 `GET /auth/permission-catalog` 拉取后本地偏序判定（与后端算法一致）

### M4 数据同步 & 实时链路 ✅
- 客户端 IndexedDB：`cache-${competitionId}` 一比赛一 DB，列表、明细、权限三套 store 分离
- 增量同步契约：`?updatedAfter=ISO&existingIds=[…]` → 后端返回 `{updated:[], deletedIds:[], serverNow}`
- Socket.IO：HTTP 端口复用，JWT 握手校验，comp-${cid} 房间订阅 + 事件 model + action 分发明细
- 前端 useResourceChanged：scope 参数（competition/global/any）精确匹配；reconcileAllIncremental 完成后派发 sync:reconciled → 组件 useMemo 重启

### M5 股票引擎优化（净买压力 + 回归干预） ✅
- 定价：`price = prevClose × (1 + 0.6×netBuyPressure + 0.4×trendBias)`，clamp ±10%
- 撮合：买入价≥卖出价 → 取中间价成交，挂单队列按时间优先 FIFO
- K 线：每轮次推进一根 1m candle（OHLC + volume），30 根自动聚合
- 回归干预：连续 3 日封板（收盘 ±10%）→ `interventionFactor = 1 - 0.3 × (days-2)`，第 5 日强制回到 70%~130% 区间

### M6 配置三层校验闭环 ✅
- L1 客户端保存：端口类型 / 必填字段 / FORMULA 括号配对预检
- L2 服务端写入：json-schema.ts + shared/engine-dsl 校验，不合格 400 报错附定位
- L3 引擎容错：evalValueSpec 坏引用兜底 0/""、safe-expression 白名单沙箱

## 5. 全局验收口径（落地后统一回归）

一份通过即可标记该层「重构完成」：

| 层 | 验收用例 | 通过标准 |
|---|---|---|
| **工程化** | `cd server && npm run lint:check` + `npm test` + `npm run build` | 0 lint error；所有 tests pass；build 无 TS error |
| **权限** | 超管新建运营用户 → 授予 manage 上限的 edit → 用该用户尝试 manage 接口 → 尝试越权给他人 grant | 403 两次；edit 接口正常；越权授予被拒 |
| **数据同步** | A 端开一个比赛，B 端登录同一比赛；A 端新建 Material，B 端不改页面 3s 内出现 | B 端出现该 Material；WebSocket comp-${cid} 房间抓到 material create 事件 |
| **股票** | 连续推进 5 轮，每轮挂大单封板；第 5 轮价格不继续封板 | 第 3+ 日 price clamp 被 interventionFactor 拉回；无连续 4 日一字板 |
| **合同** | 新建合同类型，effects 中填错误字段 key / OP args 数错 → 保存 | 返回 400，errors 中定位到具体 effectId / nodeId；不写入 |
